# 资金流向工作台安装使用指南

适用版本：GitHub v1.2.0。更新日期：2026年11月26日。

新版操作：视频模板可选“行情视频”或“行情视频-紧凑”。标准版默认24秒（行情15秒、收盘2秒、片尾7秒）；紧凑版收盘完整显示0.3秒后再定格1秒。封面新增自动、红色、蓝色选择；自动根据封面当日已获取的真实沪深合计判断，≥0红色、＜0蓝色，无数据时可手选。

这份指南从下载安装开始，带你完成第一次启动、获取数据、选择音乐、导出视频和封面。先阅读第1部分，再按自己的电脑选择第2至3部分或第4至5部分；安装成功后，从第6部分开始操作。

## 1 安装前先看这里

### 1.1 这个工具怎么运行

工作台安装在你自己的电脑上，通过浏览器操作。GitHub网页只是下载和查看说明的地方；打开GitHub网页不会直接启动工作台。使用过程中，启动时出现的黑色或白色命令窗口需要保持打开。

安装只需做一次。以后通常只要双击启动文件，再打开浏览器即可。不需要注册GitHub账号，也不需要安装Git。

### 1.2 准备好电脑和网络

- Windows：本指南以Windows 11为操作路线。
- Mac：Homebrew安装路线推荐macOS 15或更新版本、Apple芯片电脑。先点左上角苹果图标，选择“关于本机”，查看系统版本和芯片。Intel Mac或较旧系统，建议先请管理员核对安装方式。
- Python：3.10或更新版本；Windows路线安装3.13。它负责运行后台。
- FFmpeg和ffprobe：负责生成视频和检查音视频文件，通常一起安装。
- 首次安装需联网，会下载Chromium渲染组件。它与平时使用的Chrome浏览器不是同一份安装；电脑已有Chrome，也不能跳过此步骤。

真实行情还需要接口可访问。项目公开不等于数据接口向所有人开放；没有权限时，仍可使用“模拟演示”验证软件。

### 1.3 下载并解压项目

1. 在浏览器打开发布页：https://github.com/leaarningandthinking/sectorflow-studio/releases/tag/v1.2.0 。
2. 找到页面中的“Assets”附件区域，点击 SectorFlow-Studio-v1.2.0.zip。不要点击单独的.sha256校验文件代替安装包。
3. 等下载完成。Windows对ZIP点右键，选择“全部解压缩”；Mac双击ZIP解压。
4. 打开解压后的sectorflow-studio文件夹，确认能看到server.py、bootstrap.py、requirements.txt、web文件夹和两个“安装并启动”文件。
5. 把整个文件夹放到长期保存的位置，例如“文档”中的SectorFlow。后文把能直接看到bootstrap.py的这一层称为“项目文件夹”。
6. 不要在ZIP压缩包里面直接双击启动，也不要只拷贝一个启动文件到别处。

完成标志：打开项目文件夹，能看到bootstrap.py和web文件夹。Windows用户接着读第2部分，Mac用户跳到第4部分。

## 2 Windows 第一次安装运行环境

### 2.1 打开PowerShell

1. 点击任务栏“开始”按钮，输入PowerShell。
2. 打开“Windows PowerShell”或“终端”中的PowerShell页面。一般先用普通方式打开即可。
3. 下方每个命令框只复制命令本身。粘贴到窗口后按一次Enter，等执行结束，再输入下一条。不要把标题、解释或三个反引号复制进去。

### 2.2 检查Windows安装工具

输入：

```powershell
winget --version
```

看到v开头的版本号就可以继续。如果提示找不到winget，打开Microsoft Store，搜索“应用安装程序”或“App Installer”，确认发布者是Microsoft并安装或更新。完成后关闭PowerShell，重新打开，再运行上面的命令。

如果公司电脑不允许安装商店应用或软件，请联系管理员，不要自行关闭安全软件。

### 2.3 安装Python

输入：

```powershell
winget install --id Python.Python.3.13 --exact --source winget
```

等待安装结束。如果出现安装权限或协议提示，阅读并确认是本次安装的软件后，按提示操作。出现“已成功安装”或同类成功信息后继续。

如果电脑已经安装Python 3.10或更新版本，可先运行下一步的版本检查；符合要求时，不必重复安装。

### 2.4 安装视频处理工具

输入：

```powershell
winget install --id Gyan.FFmpeg --exact --source winget
```

等安装完成后，把所有PowerShell、命令提示符窗口关闭，再重新打开PowerShell。这一步很重要，否则新窗口可能尚未识别刚安装的软件位置。

### 2.5 确认三项都安装成功

依次输入，每条输完按Enter：

```powershell
py -3 --version
ffmpeg -version
ffprobe -version
```

正常结果：第一条显示Python 3.10或更新版本；第二、第三条分别显示ffmpeg、ffprobe及版本信息。后两条出现很多英文是正常的。

如果py找不到，可试python --version；如果python可用，后文的py -3也可换为python。如果ffmpeg或ffprobe找不到，先确认已经关闭旧窗口并重新打开；仍不行时，重新检查第2.4步是否成功。

## 3 Windows 第一次启动和以后怎么打开

### 3.1 从项目文件夹启动

1. 打开第1部分解压后的项目文件夹。
2. 双击“安装并启动.bat”。如果文件扩展名被隐藏，可在资源管理器“查看 → 显示 → 文件扩展名”中打开显示。
3. 第一次会出现命令窗口，依次创建本项目的运行环境、安装依赖、下载Chromium。启动工具会检查渲染组件能否正常启动；文件缺失或不能启动时会尝试重新安装。保持联网和窗口打开。
4. 下载过程中看到Collecting、Downloading、Installing或进度条，都表示程序正在工作。不要因为窗口有英文就关掉。
5. 等出现 http://127.0.0.1:8765/ 地址，通常会自动打开浏览器。没有自动打开时，手动复制这个地址到浏览器地址栏，按Enter。

完成标志：浏览器出现“资金流向视频工作台”，上方有“行情视频”和“视频封面”两个入口。

### 3.2 双击后没启动时的备用方法

1. 保持项目文件夹打开。
2. 点击资源管理器顶部显示文件夹位置的“地址栏”，输入powershell，按Enter。
3. 在新窗口输入以下命令，按Enter：

```powershell
py -3 bootstrap.py
```

如果提示找不到bootstrap.py，说明打开的位置不对。回到能看到bootstrap.py的文件夹，再重复以上步骤。如果系统安全提示阻止运行，先确认文件来自本指南的官方仓库，并按公司或系统要求处理；不要关闭系统防护。

### 3.3 以后每天怎么启动

1. 双击同一个项目文件夹里的“安装并启动.bat”。
2. 打开 http://127.0.0.1:8765/ 。
3. 看到工作台后即可操作，不需要每天重新安装Python或FFmpeg。
4. 只关闭浏览器不会关闭后台。全部工作完成后，在启动窗口按Ctrl+C，再关闭窗口。

电脑重启、启动窗口被关闭后，需要再次双击启动文件。另一个人电脑上的127.0.0.1指向他自己的电脑，不能用你的本机地址远程访问你的服务。

## 4 Mac 第一次安装运行环境

### 4.1 打开终端并检查Homebrew

1. 按Command和空格键，打开搜索。
2. 输入“终端”或Terminal，按回车打开。
3. 输入下面的命令，按回车：

```bash
brew --version
```

如果看到Homebrew版本号，直接跳到第4.3步。如果提示command not found: brew，继续第4.2步。

### 4.2 安装Homebrew

Homebrew是本路线使用的软件安装工具。官方地址：https://brew.sh/ 。复制下方完整命令到终端，按回车：

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

1. 如果要求输入Password，输入这台Mac的登录密码，再按回车。输入时通常不会显示圆点或星号，这是正常的，不是键盘失灵。
2. 如果要求按RETURN继续，阅读安装信息后按回车。
3. 如果安装要求补充Apple命令行工具，按系统提示完成安装，再继续等待。
4. 安装结束时注意“Next steps”文字。把它给出的添加Homebrew到环境的命令逐条复制到终端执行。这些命令可能包含你自己的用户名，以安装器显示的内容为准。
5. 关闭并重新打开终端，再输入brew --version。能看到版本号后再进行下一步。

如果下载失败，不要连续重输安装命令。先确认网络能打开brew.sh与GitHub；公司网络有限制时请联系管理员。

### 4.3 安装Python和视频工具

输入：

```bash
brew install python ffmpeg
```

等待安装结束。不要在这条命令前自行加sudo。已经安装时，Homebrew可能提示已安装或无需处理。

### 4.4 确认环境正常

依次输入：

```bash
python3 --version
ffmpeg -version
ffprobe -version
```

正常结果：Python显示3.10或更新版本，另外两条分别显示ffmpeg、ffprobe版本信息。三条都成功后，继续第5部分。

Homebrew当前主要支持较新的Apple芯片Mac。旧系统或Intel电脑如安装报错，请按官方兼容要求处理，不要把本指南当作所有旧Mac都适用的承诺。

## 5 Mac 第一次启动和以后怎么打开

### 5.1 双击启动

1. 在访达中打开项目文件夹。
2. 双击“安装并启动.command”。
3. 首次会创建运行环境、安装依赖并下载Chromium。启动工具会检查渲染组件能否正常启动；文件缺失或不能启动时会尝试重新安装。保持终端窗口和网络连接，不要关闭窗口。
4. 等窗口显示 http://127.0.0.1:8765/ 。浏览器未自动打开时，手动输入这个地址。
5. 看到“资金流向视频工作台”后，转到第6部分。

### 5.2 无法双击时使用终端

1. 按Command和空格，搜索并打开“终端”。
2. 在终端输入cd，再输入一个半角空格。此时先不要按回车。
3. 从访达把整个项目文件夹拖进终端窗口，系统会自动填写文件夹路径。
4. 按回车，进入项目文件夹。
5. 输入下面的命令并按回车：

```bash
python3 bootstrap.py
```

如果提示can't open file或找不到bootstrap.py，说明刚才拖入的不是项目文件夹。应拖入能直接看到bootstrap.py的那一层文件夹，而不是ZIP或单个文件。

如果出现系统安全提示，先确认下载来源，按系统或公司的要求处理；不要使用关闭系统防护的方式解决。

### 5.3 以后每天启动和停止

1. 打开项目文件夹，双击“安装并启动.command”，或使用上面的终端方法。
2. 打开 http://127.0.0.1:8765/ 。
3. 只要需要工作台，就保持启动窗口打开。
4. 完成全部导出后，在启动窗口按Control+C停止后台。

不要把项目文件夹移走后继续使用旧窗口。需要移动项目时，先停止服务；如果移动后出现环境路径错误，优先重新解压一份到最终位置，再按首次启动步骤操作。

## 6 第一次使用 先演示再获取真实数据

### 6.1 用模拟数据确认软件正常

1. 点击页面上方“行情视频”。
2. 左侧“数据模式”选择“模拟演示”。
3. “走势图内容”选择“行业”。
4. “交易日期”选择一个有效日期。
5. 等数据加载，必要时点击“生成模拟演示”。
6. 点击右上方“播放预览”，确认日期、金额、曲线和片尾能够正常显示。

完成标志：预览画面有明显的模拟标记。模拟数据只用于测试软件，不能当成真实市场数据发布。第一次测试导出时，可把背景音乐开关关闭，先排除音乐文件的影响。

### 6.2 获取指定交易日的真实数据

1. “数据模式”改为“财信证券APP · 接口数据”。
2. “接口数据源”保留“恒生资金流 · TOP榜单（默认）”，除非你明确需要兼容源。
3. “走势图内容”选择“行业”或“热门概念”。
4. 选择要制作的交易日期。刚启动时默认可能显示最近一次缓存日期，不一定是今天，要自己核对。
5. 点击“获取／重新获取接口数据”，等待取数完成。
6. 展开“数据检查与接口说明”，核对数据源、覆盖时间、排名时间、缺失分钟和实际展示数量。
7. 确认日期、数据范围正确后，再播放预览或导出。

仅修改日期时，工作台会尝试读取本地缓存。如果提示该日尚无缓存，要再点击“获取／重新获取接口数据”。非交易日、接口无历史缓存或账号无访问权限，都可能没有数据。

### 6.3 如何理解图中的名单

- 上方始终展示沪深两市数据，下方在行业与概念之间切换。
- 行业先剔除31个一级行业，再从接口最后有效分钟返回的范围中选净流入前8和净流出前7，固定这些名单回放。完整到收盘时以15:00为准；盘中或缺收盘数据时，以后台显示的排名时间为准。
- 上游可用候选不足时，会少于15个行业；不是把一级行业重新补回来。后台可查看具体数量。
- 热门概念使用净流入前10。缺失分钟不会补零；行情质量要以后台检查信息为准。

接口失败时，项目不会自动把模拟数据当成真实数据。模拟可用而真实取数失败时，先排查接口权限、日期和网络，不必反复重装Python。

## 7 导出视频 从选音乐到找到成片

### 7.1 设置总时长

1. 在左侧“视频设置”找到“视频总时长（秒）”。
2. 标准版默认填24，表示15秒行情、2秒收盘停留、7秒片尾。
3. 输入的是整段成片时长，不是仅行情部分。风险提示和品牌已包含在用户提供的片尾视频内，不需要再另加两段。
4. 建议第一次先用默认值，确认能导出后再调整。标准版总时长范围为12至189秒，紧凑版为12至188秒。

### 7.2 选择背景音乐

1. 背景音乐默认“开启”。点击“＋ 选择本地音乐”。
2. 在电脑中找到有使用授权的MP3、M4A或WAV文件，选择后打开。单个文件不能超过50MB。
3. 确认页面显示音乐文件名，可以先在音频播放器里试听。
4. “音量”默认20%，可根据试听调整。“起播秒数”表示从音乐的第几秒开始使用；起播秒数必须小于音乐总时长，不确定时保持0。
5. 如果不要背景音乐，把开关改成“关闭”。开启却没有选文件时，系统会提醒并阻止导出。

所选音乐会覆盖行情和片尾，结束时淡出；片尾原声也会保留。点击音乐文件自带的播放按钮是试听音乐，不等于完整视频预览。重开或刷新页面后，需要重新选择本地音乐。

### 7.3 预览并导出

1. 点击“播放预览”，看日期、标题、曲线、收盘停留和片尾是否正确。
2. 不满意先修改设置；满意后点击右上方“导出视频”。
3. 点击后按钮会显示“正在生成…”，预览区也会显示生成状态。保持网页和后台启动窗口打开，等待生成。生成通常需要几十秒到几分钟，取决于电脑、视频时长和数据量。不要连续重复点击。
4. 完成后浏览器会发起下载。若浏览器显示保存位置选择框，选择文件夹并保存。
5. 打开浏览器右上方“下载”列表找到MP4；一般也可到电脑“下载”文件夹查找。
6. 双击MP4，检查总时长、画面、音乐和片尾后再使用。

### 7.4 没看到下载时去哪里找

默认行业TOP源文件名类似：2026-11-16_top_fund_flow.mp4。概念文件名会多concept。视频也会保存在项目文件夹的output文件夹里。相同日期、同一数据源和类别再次导出，会使用同一文件名；要保留不同版本，请先另存或改名。

## 8 导出视频封面与每天的操作顺序

### 8.1 生成独立视频封面

1. 点击页面上方“视频封面”，不要点行情预览下的“导出行情截图”。后者是走势图截图，和独立封面是两种功能。
2. 核对“封面日期”。默认按北京时间当天自动更新。你制作历史视频时，需要手动选对应日期。
3. 也可以点“使用当前视频日期”，把行情页面所选日期带过来；点“恢复今天”回到当天自动日期。
4. 选择尺寸：3比4对应1200×1600，9比16对应1080×1920，按发布平台需要选择。
5. 检查蓝色封面预览中的日期和文字。3比4与9比16分别使用对应比例的蓝色底图，日期会根据所选日期自动生成。
6. 点击“导出封面”，在浏览器下载列表或电脑“下载”文件夹找到JPG。
7. 文件名类似：2026-11-16_主力资金流向_封面.jpg。需要两种尺寸时，分别导出并及时改名，避免混淆。

封面文件严格不超过500,000字节（500KB）。程序优先保留原尺寸并调整压缩质量，必要时才等比例缩小。独立封面不需要选择音乐，也不依赖真实数据接口。封面在浏览器本地生成，通常不会保存到项目的output文件夹。

### 8.2 每天制作一条视频的顺序

1. 双击本机对应的“安装并启动”文件，打开工作台。
2. 选择真实数据模式、行业或概念，核对日期，再获取接口数据。
3. 查看数据检查信息，确认数据覆盖和名单数量。
4. 选择背景音乐，核对总时长，播放预览。
5. 导出MP4，并打开成片检查。
6. 切换到“视频封面”，把封面日期改成同一个交易日，导出JPG。
7. 将视频和封面放到自己的素材文件夹，确认无误后停止后台。

### 8.3 哪些文件不要删

保留整个项目文件夹，尤其是web、bootstrap.py、server.py、requirements.txt和.venv。web里有图表库、字体和片尾，缺少会影响预览或导出。

自己的视频和音乐另做备份。不要把含有.venv的整套运行环境复制给另一台电脑直接用；另一台电脑应从ZIP重新安装。

## 9 常见问题 先按现象处理

### 9.1 网页打不开或提示无法访问

先看启动窗口是否还在运行。停止了就重新启动；运行着就确认地址是 http://127.0.0.1:8765/ ，没有写成https，也没有漏掉8765。电脑重启后，旧浏览器标签页不会自动恢复后台。

### 9.2 提示端口占用或Address already in use

先试着打开8765页面；可能后台已经在运行。要再启动另一份，在项目文件夹的终端运行：

Windows：
```powershell
py -3 bootstrap.py --port 8766
```

Mac：
```bash
python3 bootstrap.py --port 8766
```

这次浏览器地址也要改成 http://127.0.0.1:8766/ 。不要为了解决端口占用随意结束不认识的进程。

### 9.3 页面能用 但点击导出视频失败

先确认音乐开关和文件。若提示Executable doesn't exist、playwright install，或“视频渲染组件缺失”，说明Chromium文件缺失，即使电脑已有Chrome也需要修复。

先等现有导出结束，停止后台。在项目文件夹打开终端，按系统运行：

Windows PowerShell：
```powershell
.\.venv\Scripts\python.exe -m playwright install chromium
py -3 bootstrap.py
```

Mac：
```bash
.venv/bin/python -m playwright install chromium
python3 bootstrap.py
```

等浏览器组件下载完成后再启动。回到页面刷新、重新选择音乐，再导出。不要删除正在使用的浏览器缓存。若提示.venv里的Python不存在，回到首次启动步骤创建环境。

### 9.4 还是没下载成功

等页面状态显示完成后，先看浏览器下载列表，再看项目output文件夹。v1.1.0会在预览区显示导出状态，失败时显示明显的错误提示；左侧下方“工作台状态”也会同步显示。根据提示处理后再试，不要因为没有弹窗就连续点击。

## 10 取数问题 更新方式和求助材料

### 10.1 真实数据取不到 或行业少于15个

先检查日期是否为目标交易日，再点击“获取／重新获取接口数据”。然后展开“数据检查与接口说明”，查看错误、覆盖时间和接口返回数量。模拟演示成功只证明软件能运行，不证明真实接口有权限。当前默认行业规则是剔除一级行业后再选8加7；上游候选不足就按实际数量展示，软件不会编造不足的数据。

如果需要新的接口地址，请向项目维护者索取正确地址。没有人提供地址时，先用模拟演示，不要随机修改data_source.py中的代码。

### 10.2 视频在片尾没有音乐

确认背景音乐开关开启且已选择音乐；再确认播放的是本次重新导出的MP4。旧文件不会因软件更新而自动变化。工作台音乐覆盖整段视频，最后会淡出；关闭开关时只保留片尾原声，片尾本身无明显声音时听起来会安静。

### 10.3 安装下载中断

保留报错内容，检查网络，恢复网络后重新运行启动文件。首次安装有依赖安装和Chromium下载两个阶段，不要看到其中一个完成就关闭窗口。遇到证书错误，不要通过关闭证书验证处理；公司电脑请让管理员检查网络与证书。

### 10.4 后续怎样更新

1. 先停止旧后台。
2. 把要保留的视频、封面和音乐备份到独立文件夹。
3. 从仓库发布页下载新版本ZIP，解压到一个新文件夹，按首次启动方式安装。
4. 用模拟演示验证后，再获取真实数据和制作视频。不要把旧版本.venv复制到新版本。
5. 以发布页的版本号与更新说明为准；已下载的旧ZIP和旧视频不会自动更新。
